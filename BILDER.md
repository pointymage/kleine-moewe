# Bilder für „Kleine Möwe“

So funktioniert es:
1. Erzeuge die Bilder mit einem Bild-KI-Programm (z. B. ChatGPT, Gemini oder Bing Image Creator).
2. Speichere sie als **PNG** unter dem angegebenen Dateinamen im Ordner `kleine-moewe\img\`.
3. Sag Claude Bescheid: Die Bilder werden eingebaut und hochgeladen.

Fehlende Bilder sind kein Problem, dann bleibt das Emoji. Du kannst also nach und nach austauschen.

## Stil-Satz (immer vor jeden Prompt setzen)

> Casual mobile game item icon, glossy hand-painted cartoon style like a cozy merge game, soft shading, warm colors, thick clean outline, single object centered, **plain pure white background**, no text, no shadow on ground, square 1:1.

Der weiße Hintergrund wird im Spiel automatisch unsichtbar.
